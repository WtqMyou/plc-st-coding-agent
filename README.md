## 本地查看与离线检查

需要 Python 3.10 及以上。在仓库目录执行：

```powershell
cd agent_dev_r9
python -B -X utf8 -m unittest discover -s tests -p "test_v2*.py" -v
```

上述命令运行离线回归，不调用付费模型。真实平台编译还需要单独安装 CODESYS、OpenPLC 并调整本机路径。真实模型实验会产生费用，历史启动命令保留用于审计；不要同时启动旧实验或为复现而清空费用账本。

目前的形式检查是有限输入域和有限步数的有界检查，R9 共 179 条 LTL、24 条仅由模拟测试覆盖的性质；不代表全部性质已证明，也不等同于实际 PLCVerif 或现场 PLC 验证。
