## 本轮修复

- Codex 进程使用文件保存标准输出与错误输出，避免子进程继承输出管道后使 timeout 收尾继续阻塞。任务提示保存于隔离目录，不包含参考解、完整 expected 或供应商密钥。
- 截止时终止该次 CLI 进程树；上游失败时立即停止 CLI，不等待客户端重连。一次候选仍最多发送一次上游请求，保存第一项故障原因。
- 新增专用 CLI 超时恢复：只接受原始单次空候选、当前源码通过的离线取消验证，以及最新同模型的未结算超时事件。保留全部已知费用和未知预留；同一证据不能再次解除后来的失败。
- 协议与资源限制保持：DeepSeek Responses、MiniMax Chat，420 秒请求、450 秒 CLI、600 秒整题、16384 token 输出，累计阶段上限 5/20/65/75 元。
- 当前适配契约实际为 portable-frame-v3：合法带类型数字字面量已支持，FIFO 规约改用显式 capacity。此修复来自旧会话最后一次离线开发，四份完整保存候选已通过双平台和 27/27 用例，短时 LTL 超时未计通过。
