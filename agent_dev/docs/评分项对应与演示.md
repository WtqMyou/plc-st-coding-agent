## 接手成员的报告材料

报告可以直接引用验收报告、平台安装记录、修订记录、实验协议和 project_index。统计数字须取本轮 JSON/CSV，不能沿用成员一历史文档中的全规约通过结论。

当前两框架统一使用 portable-frame-v4。生成后的代码不会被静默改写；适配发生在评测前的题面和接口冻结阶段。原 v2.1 的平台工程及离线全题矩阵作为历史证据保留。

R8 已完成，不再执行旧启动命令。下一阶段位于独立的 agent_dev_r9 副本，使用单独的诊断计划、费用上限和验证证据。

启动前先核对 active_run.json 的实际进程，避免已有流程运行时重复启动。当前流程已完成身份、协议和输出边界核验，使用同一共享账本；包内预算快照不可用于退回已消耗金额。

## 已知数据边界

通用 VARIANT FIFO 未量化任意调用方类型/容量，原契约的形式检查返回无法判定。适配版是 DINT 有界特化。self-hard-04 的 rotated 字段沿用既有输入契约，表示轮换请求。五道新题的工艺合理性仍由组内评审确认；工程修订详见二次更新整合说明。
