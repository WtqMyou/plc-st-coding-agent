## 复验后修订

**蒸汽单位。** v1.2 把流量标为 t/h，但使用 `flow*dt/1000` 吨；原草案明确为 kg/s。本版本将题面和变量单位恢复为 kg/s，保留全部公式和数字期望。没有把错误单位换算带入正式提示词。

**超压证据中断。** 原参考解只在停机或仪表失效时清零阀证据；压力回落到 4500 以下时漏清零，导致两个分离片段被误计为连续三拍。参考解增加该分支清零。新增独立轨迹包含“两拍超压偏差→一拍正常压力→重新三拍超压偏差”，并确认故意恢复旧实现时测试失败。题面明确全部条件连续成立；WORD 掩码说明改为 16 位，仅使用低四位。

**PI 初始化的版本差异。** 草案要求初始化后再留一个进入拍，但 v1.2 的 q2 明确期望 `normalMode=TRUE`。本版本沿用已交付的 q2 和算法：初始化记录当前模式，下一合法拍模式未变则正常运算；每次实际模式变化均保持输出，即使连续扫描都改变模式。题面第 5 条与此对齐，并恢复手动设定值的合法范围前提。没有用更改 q2 期望来迁就另一种策略。若团队选用草案策略，必须另升数据版本并同步用例、参考解、规约和实验冻结。

**原生编译接口。** CODESYS 将 `dt` 识别为日期时间类型别名，三题的原接口不能通过。`portable-frame-v2` 在两框架和两平台中统一将输入改为 `scanSeconds`，同步题面、用例键和 LTL；保持秒单位、数据类型和输出断言。原题 JSON 和原接口编译失败证据单独保留，生成后的模型代码不会再被偷偷改名。

九项新增回归还覆盖：上游 57 条用例哈希、全量统计与索引、十六进制 LTL 真正求值、熄火锁存与复位按住、累计量复位按住、模糊控制带非零 bias 的复位、超压证据重计数及错误实现拦截、PI 连续模式切换、单题 CLI 不把截断或无法判定当作通过。

## 复现与证据

在 agent_dev 运行：

```powershell
python -B -X utf8 scripts/rebuild_selfmade.py
python -B -X utf8 scripts/acceptance.py
python -B -X utf8 scripts/export_portable.py
python -B -X utf8 scripts/codesys_reference_batch.py --adapted
python -B -X utf8 scripts/refresh_native_evidence.py --platform openplc --adapted
python -B -X utf8 -m stbench matrix --offline --adapted --out evidence/offline_matrix_v2.1/summary.json
python -B -X utf8 scripts/integration_smoke.py
python -B -X utf8 -m stbench verify-refs --mc --out evidence/reference_mc_current.json
```

`rebuild_selfmade.py` 默认检查生成器和 15 题 JSON/索引有无漂移；需要导出时使用 `--write`，统一执行两组生成器并保留工程评审元数据。ST 参考解始终以 `datasets/selfmade/tests/*.reference.st` 为唯一执行源，不再维护一份嵌入字符串。

上游来源和导入前后哈希见 `evidence/upstream_v1.2_import.json`；五题原用例哈希见 `evidence/upstream_v1.2_cases.json`。旧 378 条用例由原始清单独立保护。v2.0 原交接 ZIP 未覆盖，源代码增量见 `evidence/revisions/v2.0_to_v2.1.patch`。实际检查结果及规约截断范围以本版本验收报告和 JSON 为准。

历史原文存于 `docs/upstream_v1.2`，其中“79 条 hold”不表示无限状态证明；其旧版检查器和本版本的截断判定不同，不能直接替代本轮验证结果。当前正式实验入口将完整覆盖 35 题；若最终缩减至 30 题，应先确定名单、冻结新版本并对四组使用相同题集。

当前正式验收入口为 `python -m stbench`、`scripts/acceptance.py` 和本文列出的平台/联调脚本。`scripts/verify_one.py`、`mc_all.py` 和 `dataset_stats.py` 的 MC 状态也已同步修正；历史库模块 `stbench.verify_specs` 的旧汇总输出不作为验收证据，复现旧材料时请改用主 CLI。
