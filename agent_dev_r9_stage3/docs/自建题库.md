## 1. `self-easy-01` — 分段采样平均值计算中的除零与边界保护

| 难度 | 用例模式 | 用例数 | 目标 POU |
|---|---|---|---|
| easy | `single` | 6 | `FUNCTION_BLOCK` |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `enable` | 输入 | `BOOL` | TRUE 时更新平均值，FALSE 时保持 |
| `values` | 输入 | `ARRAY[1..8] OF INT` | 本周期采集到的原始样本（1..8 号站） |
| `count` | 输入 | `INT` | 本周期有效的样本个数，合法范围 0..8 |
| `avgEnable` | 输入 | `BOOL` | 计算使能，通常接在物位低联锁之后 |
| `avgOut` | 输出 | `REAL` | 平均输出 |

### 控制要求

写一个功能块 FB，在每个扫描周期计算一组采样值的平均值。
控制要求：
1. enable 为 TRUE 时更新平均值，为 FALSE 时 avgOut 保持上一周期的值不变；
2. count 为本周期有效样本个数，合法范围 0..8；count 为 0 时**不得发生除零**，此时 avgOut 保持不变；
3. count 大于数组长度 8 时，只按前 8 个样本计算，不得越界访问；
4. avgEnable 为 FALSE 时视为未投入自动，同样保持 avgOut 不变；
5. 整数相加可能超过 INT 范围，求和过程中应使用更宽的类型（DINT/LINT）避免溢出；
6. 结果以 REAL 输出，保留原始精度，不做四舍五入到整数。

### LTL 规约（形式化验收条件）

| # | 类别 | 表达式 | 验证方式 |
|---|---|---|---|
| S1 | 安全性 | `G((count <= 0) -> avgOut = prev(avgOut))` | plcverif |
|  |  | _count 为 0 或为负时，不得发生除零，avgOut 应在**当周期**保持不变。_ |  |
| S2 | 安全性 | `G(!enable -> avgOut = prev(avgOut))` | plcverif |
|  |  | _enable 为 FALSE 时，avgOut 应在当周期保持不变，不得被改写。_ |  |
| S3 | 安全性 | `G(avgOut = avgOut)` | plcverif |
|  |  | _avgOut 在任何输入下都不是 NaN（数值健全性）。越界访问本身由解释器直接判运行期错误，不在 LTL 层表达。_ |  |
| S4 | data | `` | simulation |
|  |  | _在 enable 且 count 合法时，avgOut 等于所选样本的算术平均。_ |  |

## 2. `self-easy-02` — 储罐高低液位联锁与报警自保持

| 难度 | 用例模式 | 用例数 | 目标 POU |
|---|---|---|---|
| easy | `sequence` | 8 | `FUNCTION_BLOCK` |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `tankLevel` | 输入 | `REAL` | 储罐液位百分比 0..100 |
| `outletFlow` | 输入 | `REAL` | 出口流量 m³/h |
| `inletPermit` | 输入 | `BOOL` | 进料许可（工艺联锁允许进料） |
| `resetBtn` | 输入 | `BOOL` | 复位按钮（上升沿有效） |
| `pumpRun` | 输出 | `BOOL` | 进料泵运行命令 |
| `alarmHigh` | 输出 | `BOOL` | 高液位报警（自保持，需复位） |
| `alarmLow` | 输出 | `BOOL` | 低液位报警（自保持，需复位） |
| `outletValveOpen` | 输出 | `BOOL` | 出口阀开命令 |

### 控制要求

写一个功能块 FB，实现储罐的进料联锁。
控制要求：
1. tankLevel 低于 85.0 且不低于 15.0、inletPermit 为 TRUE、且当前无高液位报警时，pumpRun 置 TRUE，outletValveOpen 置 TRUE；
2. tankLevel **达到或超过** 85.0 时，alarmHigh 置 TRUE（自保持），并立即停止进料泵；
3. tankLevel **达到或低于** 15.0 时，alarmLow 置 TRUE（自保持），并关闭出口阀；
4. resetBtn 的**上升沿**同时清除两个报警；按住不放只算一次复位；
5. 报警存在期间，即使按下复位按钮，复位也不生效（报警优先）；
6. 所有报警清除、条件满足后，系统自动恢复运行，不需要重新上电。

### LTL 规约（形式化验收条件）

| # | 类别 | 表达式 | 验证方式 |
|---|---|---|---|
| S1 | 安全性 | `G(tankLevel >= 85.0 & !rising(resetBtn) -> alarmHigh)` | plcverif |
|  |  | _液位不低于 85.0 时，高液位报警必须在当周期置位。_ |  |
| S2 | sequencing | `G(alarmHigh & !X(rising(resetBtn)) -> X(alarmHigh))` | plcverif |
|  |  | _高液位报警置位后，在复位按钮上升沿出现之前必须保持。_ |  |
| S3 | 安全性 | `G(alarmHigh -> !pumpRun)` | plcverif |
|  |  | _高液位报警有效期间，进料泵不得运行（停止优先于启动）。_ |  |
| S4 | 安全性 | `G(tankLevel <= 15.0 -> !outletValveOpen)` | plcverif |
|  |  | _液位不高于 15.0 时，出口阀必须在当周期关闭。_ |  |
| S5 | 安全性 | `G(!inletPermit -> !pumpRun)` | plcverif |
|  |  | _无进料许可时，进料泵不得运行。_ |  |

## 3. `self-medium-01` — 配料配方装载与校验（数组越界与浮点区间）

| 难度 | 用例模式 | 用例数 | 目标 POU |
|---|---|---|---|
| medium | `single` | 7 | `FUNCTION_BLOCK` |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `recipe` | 输入 | `ARRAY[1..8] OF ST_Recipe` | 配方槽位 1..8，槽位 recipeID=0 表示空 |
| `selSlot` | 输入 | `INT` | 操作员选中的槽位，合法范围 1..8 |
| `loadCmd` | 输入 | `BOOL` | 装载命令（上升沿触发一次装载） |
| `running` | 输入 | `BOOL` | 当前是否处于生产状态 |
| `valid` | 输出 | `BOOL` | 配方校验通过 |
| `loadedID` | 输出 | `INT` | 已装载的配方号，无配方时为 0 |

### 控制要求

写一个功能块 FB，从配方库中按槽位装载配方并校验。
控制要求：
1. recipe 是 8 个槽位的配方数组，槽位 recipeID = 0 表示空槽；
2. selSlot 是操作员选中的槽位，合法范围 1..8；**越界时必须判为非法，不得访问数组外**；
3. loadCmd 的**上升沿**触发一次装载；按住不放不得重复装载；
4. 校验规则（**全部满足**才算 valid）：槽位非空；totalRatio 在 99.0..101.0 之间（含端点）；temperature 在 30.0..180.0 之间（含端点）；
5. 校验通过时 valid := TRUE 且 loadedID 更新为该槽位的 recipeID；校验失败时 valid := FALSE 且 loadedID 归 0；
6. running 为 TRUE 表示正在生产，此时装载命令无效，loadedID 保持原值。

### LTL 规约（形式化验收条件）

| # | 类别 | 表达式 | 验证方式 |
|---|---|---|---|
| S1 | 安全性 | `G(!running & rising(loadCmd) & (selSlot >= 1) & (selSlot <= 8) & (recipe[selSlot].recipeID = 0) -> !valid)` | plcverif |
|  |  | _选中的槽位为空（recipeID = 0）时，装载必须判为非法，且不得改变已装载的 loadedID。_ |  |
| S2 | 安全性 | `G(!running & rising(loadCmd) & (selSlot >= 1) & (selSlot <= 8) & (recipe[selSlot].totalRatio < 99.0) -> !valid)` | plcverif |
|  |  | _总配比越界（totalRatio < 99 或 > 101）时装载必须判为非法。_ |  |
| S3 | 安全性 | `G(!running & rising(loadCmd) & (selSlot >= 1) & (selSlot <= 8) & (recipe[selSlot].temperature > 180.0) -> !valid)` | plcverif |
|  |  | _温度越界（temperature < 30 或 > 180）时装载必须判为非法。_ |  |
| S4 | 安全性 | `G(running & X(running) -> X(loadedID = prev(loadedID)))` | plcverif |
|  |  | _生产运行中（running），装载命令不得改变 loadedID。注意必须要求 running 在相邻两拍都成立——只要求起始拍成立的话，下一拍 running 撤销、装载被接受，就是合法行为。_ |  |
| S5 | 安全性 | `G(!running & rising(loadCmd) & ((selSlot < 1) | (selSlot > 8)) -> !valid)` | plcverif |
|  |  | _槽位越界（selSlot < 1 或 > 8）时必须判为非法，不得访问数组外内存。_ |  |
| S6 | sequencing | `G(loadCmd & prev(loadCmd) -> loadedID = prev(loadedID))` | plcverif |
|  |  | _装载命令只在上升沿生效，电平保持期间不得重复装载。_ |  |

## 7. `self-medium-05` — 合格蒸汽产量与净收益累计（闭区间判定 + 数据故障冻结）

| 难度 | 用例模式 | 用例数 | 目标 POU |
|---|---|---|---|
| medium | `sequence` | 11 | `FUNCTION_BLOCK` |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `enable` | 输入 | `BOOL` | 计量使能 |
| `resetBtn` | 输入 | `BOOL` | 清零按钮（上升沿有效） |
| `dt` | 输入 | `LREAL` | 本周期时长（s），合法 0 < dt <= 10 |
| `steamFlow` | 输入 | `LREAL` | 蒸汽流量（kg/s），合法 0..90 |
| `fuelFlow` | 输入 | `LREAL` | 燃料流量（kg/s），合法 0..6 |
| `steamTemp` | 输入 | `LREAL` | 蒸汽温度（℃） |
| `steamPressure` | 输入 | `LREAL` | 蒸汽压力（kPa） |
| `qualified` | 输出 | `BOOL` | 本周期蒸汽是否合格 |
| `dataFault` | 输出 | `BOOL` | 数据故障（参数越界） |
| `qualifiedTon` | 输出 | `LREAL` | 累计合格蒸汽产量（t） |
| `fuelTon` | 输出 | `LREAL` | 累计燃料消耗（t） |
| `revenue` | 输出 | `LREAL` | 累计收入（元） |
| `cost` | 输出 | `LREAL` | 累计成本（元） |
| `netProfit` | 输出 | `LREAL` | 累计净收益（元） |

### 控制要求

写一个功能块 FB，按扫描周期累计锅炉的合格蒸汽产量、燃料消耗与净收益。
控制要求：
1. 合格判据：steamTemp 在 [447.0, 453.0] 且 steamPressure 在 [3750.0, 3850.0]（**闭区间**，端点合格）；
2. 本周期合格且 enable=TRUE 且无数据故障时，qualifiedTon += steamFlow * dt / 1000.0（kg/s × s ÷ 1000 → t）；无论是否合格，只要 enable 且无故障，fuelTon += fuelFlow * dt / 1000.0；
3. 数据故障判据：dt <= 0.0 或 dt > 10.0 或 steamFlow 不在 [0,90] 或 fuelFlow 不在 [0,6]；故障拍**不累计**，累计值保持不变；

## 8. `self-medium-06` — 温度模糊控制与输出钳位（重心法 + 历史误差清除）

| 难度 | 用例模式 | 用例数 | 目标 POU |

### 接口定义

| `resetBtn` | 输入 | `BOOL` | 复位（上升沿清除历史误差） |
| `sensorValid` | 输入 | `BOOL` | 温度传感器数据有效 |

| `temperature` | 输入 | `REAL` | 温度测量值（℃） |

### 控制要求

写一个功能块 FB，用九条规则的温度模糊控制器计算加热功率。
控制要求：
1. e = setpoint - temperature；de = (e - ePrev) / dt，**首拍**或历史被清除时 de = 0；
2. x = clamp(e / 10.0, -1, 1)，y = clamp(de / 2.0, -1, 1)；

6. fault = NOT sensorValid OR dt <= 0.0 OR dt > 10.0；fault、enable=FALSE 或 resetBtn 上升沿时：power=0、correction=0，并清除历史（ePrev=0、历史标志=FALSE）。

## 9. `self-hard-01` — 带确认与优先级的报警管理（四态报警模型）

| 难度 | 用例模式 | 用例数 | 目标 POU |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `flowLow` | 输入 | `BOOL` | 流量低开关量输入 |
| `ackBtn` | 输入 | `BOOL` | 确认按钮（上升沿有效） |
| `sensorOK` | 输入 | `BOOL` | 传感器健康状态（FALSE 表示断线） |
| `alarmActive` | 输出 | `BOOL` | 报警激活（条件仍存在） |
| `alarmAcked` | 输出 | `BOOL` | 报警已确认（条件消失后自动清除） |
| `highHigh` | 输出 | `BOOL` | 高优先级报警（传感器断线导致） |

### 控制要求

写一个功能块 FB，实现 ISA-18.2 风格的四态报警管理。
控制要求：
1. 报警条件成立（flowLow = TRUE）→ alarmActive 置 TRUE，alarmAcked 置 FALSE；
2. 报警未被确认时，即使条件消失，alarmActive 仍保持 TRUE（报警在未确认前不得消失），同时 alarmAcked 置 TRUE 表示'已转为待确认清除'；
3. ackBtn 的**上升沿**确认报警：若此时条件已消失 → alarmActive 与 alarmAcked 一起清除；若条件仍存在 → 只置 alarmAcked，报警继续；
4. sensorOK 为 FALSE 表示传感器断线 → highHigh 置 TRUE（高优先级）；**高优先级报警与低优先级报警必须同时可见，不得互相抑制**；
5. 传感器恢复后，highHigh 自动清除，低优先级仍按 1~3 的规则独立判定。

## 10. `self-hard-02` — 批次工艺阶段与运行时长统计（无外部时钟）

| 难度 | 用例模式 | 用例数 | 目标 POU |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `startBtn` | 输入 | `BOOL` | 批次开始（上升沿有效） |
| `abortBtn` | 输入 | `BOOL` | 中止按钮（直接中止批次） |
| `setpoint` | 输入 | `REAL` | 工艺设定值 |
| `pv` | 输入 | `REAL` | 过程测量值 |
| `maxDuration` | 输入 | `INT` | 本批次允许的最长持续时间（秒） |
| `elapsed` | 输出 | `INT` | 已运行秒数 |
| `phase` | 输出 | `INT` | 阶段号：0=空闲 1=升温 2=保温 3=完成 9=已中止 |
| `timeout` | 输出 | `BOOL` | 超时标志 |

### 控制要求

写一个功能块 FB，管理一个间歇反应釜的批次生命周期。
控制要求：
1. startBtn 的上升沿开始一个新批次：phase := 1，elapsed := 0，timeout := FALSE；
2. phase = 1（升温）时，每个扫描周期 elapsed 加 1；当 pv **达到或超过** setpoint 时进入 phase = 2（保温）；
3. phase = 2（保温）时，elapsed 继续每周期加 1，直到操作员按确认或超时；
4. **超时判定**：elapsed 达到 maxDuration 时 timeout 置 TRUE，并进入 phase = 3（完成）；
5. **中止按钮优先级最高**：任何阶段按下 abortBtn 都立即进入 phase = 9，且 elapsed 停止累加；
6. 进入中止态后不得自动恢复，必须重新按 startBtn 并在新批次中清零一切状态；
7. **不得使用任何系统时钟**（无 TIME/TON 等计时器），时长只能来自扫描周期计数。

写一个功能块 FB，实现燃烧器的火焰联锁与烟气氧量修正。

| `outletFeedback` | 输入 | `INT` | 减温减压阀开度反馈（%） |
| `resetBtn` | 输入 | `BOOL` | 复位按钮（上升沿有效） |

| `diagnosticActive` | 输出 | `BOOL` | 存在有效诊断线索 |

### 控制要求

写一个功能块 FB，实现母管超压联锁，并在跳闸时记录**故障线索**。
控制要求：
1. 压力有效判据 pressureValid；>= 4500.0 kPa 判超压；
2. 跳闸条件（任一成立）：runRequest 且 pressureValid 且 pressure >= 4500.0；runRequest 且 NOT pressureValid（数据失效按最坏情况处理）；跳闸与本拍线索同拍生效；
3. tripLatched 自保持；清除条件：resetBtn 上升沿 且 NOT runRequest 且 pressureValid 且 pressure <= 4200.0（滞环，防抖动）；
4. 线索位（currentCauseMask，WORD，本拍重新计算）：bit0=1 变送器失效；bit1=2 减温减压阀卡滞（outletCmd>=50 且 outletFeedback<=10 连续 **3 拍及以上**，每拍须同时满足运行、压力有效且压力>=4500；任一中断清零）；bit2=4 燃烧过剩（fuelFlow >= 4.0 且 steamFlow <= 10.0）；若超压但以上线索都不成立，置 bit3=8（未定位）；NOT runRequest 时线索为 0；
5. latchedCauseMask：tripLatched 为 TRUE 时把 currentCauseMask **按位或**并入（32 位字，不会溢出），复位时清零；
6. fuelPermit = runRequest AND NOT tripLatched；diagnosticActive = (currentCauseMask <> 0)。

## 15. `self-hard-07` — 串级 PI 手自动无扰切换（积分预置 + 切换拍保持）

| 难度 | 用例模式 | 用例数 | 目标 POU |
|---|---|---|---|
| hard | `sequence` | 13 | `FUNCTION_BLOCK` |

### 接口定义

| 变量 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `mode` | 输入 | `INT` | 0=手动 1=外环手动/内环自动 2=串级全自动 |
| `resetBtn` | 输入 | `BOOL` | 复位（上升沿） |
| `dt` | 输入 | `REAL` | 本周期时长（s），合法 0 < dt <= 10 |
| `tempSP` | 输入 | `REAL` | 温度设定（℃） |
| `tempPV` | 输入 | `REAL` | 温度测量（℃） |
| `flowPV` | 输入 | `REAL` | 流量测量（t/h） |
| `manualFlowSP` | 输入 | `REAL` | 流量设定手操值（t/h） |
| `manualValve` | 输入 | `REAL` | 阀位手操值（%） |
| `flowSP` | 输出 | `REAL` | 流量设定输出（t/h），钳位 0..50 |
| `valveCommand` | 输出 | `REAL` | 阀位命令（%），钳位 0..100 |
| `fault` | 输出 | `BOOL` | 模式或参数非法 |
| `normalMode` | 输出 | `BOOL` | 本拍按正常 PI 规则运算（非初始化/切换拍） |

### 控制要求

写一个功能块 FB，实现温度-流量串级 PI 控制的三模式无扰切换。
控制要求：
1. mode：0=手动、1=外环手动/内环自动、2=串级全自动；mode 不在 0..2、dt<=0 或 dt>10 判 fault；
2. 初始化、复位上升沿、fault 三者的当拍：flowSP = manualFlowSP、valveCommand = manualValve，并把积分项预置为无扰值：iT = flowSP - KpT*(tempSP-tempPV)，iF = valveCommand - KpF*(flowSP-flowPV)（KpT=1.0，KpF=2.0）；
3. **模式切换的当拍不做积分**：阀位保持上一拍；切到 mode=2 时 flowSP 也保持上一拍，切到其它模式时 flowSP 跟 manualFlowSP；切换拍同时按上面公式重算 iT、iF；
4. 正常运算拍（normalMode=TRUE）：
   mode=0：flowSP=manualFlowSP、valveCommand=manualValve，重算 iT、iF；
   mode=1：flowSP=manualFlowSP、iT 按公式跟踪；eF=flowSP-flowPV，iF += KiF*eF*dt（KiF=0.5），valveCommand=clamp(KpF*eF+iF,0,100)，随后 iF=valveCommand-KpF*eF；
   mode=2：eT=tempSP-tempPV，iT += KiT*eT*dt（KiT=0.2），flowSP=clamp(KpT*eT+iT,0,50)，iT=flowSP-KpT*eT；再按 mode=1 的公式算内环；
5. 模式切换的识别：非初始化拍比较 mode 与内部上一模式；即使连续两拍切换也必须识别；初始化记录当前 mode；下一合法非复位拍 mode 未变则正常运算（与 q2 一致），mode 变化则切换保持；
6. normalMode 输出：本拍按正常 PI 规则运算则为 TRUE，初始化/切换/故障拍为 FALSE。调用方保证 manualFlowSP 在 [0,50]、manualValve 在 [0,100]；输入均为有限数。
