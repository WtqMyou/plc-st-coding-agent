# STBench r6 确认包的 13 题修订

解压后用 Python 3.13 执行 `python -B -X utf8 run.py`。入口遍历 datasets 下全部题目，读取同目录 tests 下的参考 ST，分组执行功能用例并在实际扫描快照上检查 LTL。results.json 记录逐题结果。每个命名序列单独初始化。三项反例检查分别将去抖阈值改成严格大于、取消升档重选备泵、将遇障锁故障改为空闲，要求用例能拒绝这些错误实现。

本包源自给 lym 的 r6 确认包。果酱泵采用随包来件对照中的毫秒接口和 25 个用例，替换历史扫描计数版。五泵采用来件中升档重选备泵的契约，同时保留两版用例。闸门以对照版为起点，统一为任何状态遇障当拍停机锁故障，障碍解除后需双键组合新沿复位，再发新命令才能运行。

蒸汽题明确复位与禁用、故障的优先级，模糊控制题补齐乘积权重，串级 PI 题明确复位与故障同拍时的故障位。配方规约补全配比与温度上下界、空槽清零，并用相邻拍直接表示连续生产时编号保持。灌装规约直接检查阀门开启当拍的启动沿，覆盖首拍。

评分依据是本修订的 requirements、variables、specs 和 test_cases。raw_text、provenance 和原有验证标签属于上游来源记录，其中的路径可指向早期工程。本包仅提供这 13 题的功能和有限轨迹验证。stbench 执行引擎来自本地 F1.3 工程。确认包缺少另外 22 道 r6 题、r5 正式判分器及全库双平台验收入口。复跑不需要模型 API。
