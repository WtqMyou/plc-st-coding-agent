# 批次生命周期

队友的批次题有 17 条功能用例、5 条非空 LTL，本版为 **29/29、6/6**。来件 S4 约束的是终止阶段集合 {3,9}。本版在没有新命令时要求保持原阶段，同时保留中止优先和重新启动的例外。[原始数据与逐字段对照](peer_baseline.json)

首拍给出启动上升沿，设 maxDuration=1，随后两拍松开启动且不按中止。正确阶段依次为 1、3、3。如果程序从完成态自行退回空闲，第三拍实际读到 0；如果擅自转入中止，则读到 9。S4 能分别定位这两种错误。S6 另外覆盖条件达标、等于门槛与保温后温度回落的情况。[实际 ST 修改与轨迹](batch_requirements.json)

从零计数启动，阈值取 256。正确程序在第 256 个运行拍完成，elapsed=256；8 位计数错解输出 0。因启动拍不计入运行时长，这次差异出现在整段输入的第 257 拍。题面要求用扫描拍计数，时间类型、持续时间常量和时间转换的禁用另按源码检查。[长计数输入](control_loop_audit.json) · [源码约束](batch_clock_policy.json)
