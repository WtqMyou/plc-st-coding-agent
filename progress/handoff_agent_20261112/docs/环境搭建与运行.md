# 环境搭建与运行

## 看结果与做演示

打开根目录HTML即可查看主要成果，不需要Python、模型账号、Git、Codex CLI或CODESYS。图表已提供PNG和SVG，表格可用Excel打开。

命令行回放与本地功能复验需要Python 3.10及以上，开发测试机实际使用Python 3.12。核心离线工具采用标准库；PNG/SVG已生成，接收者无需安装matplotlib。

在包根目录运行：

```powershell
python -B -X utf8 06_离线工具/offline_demo.py --case all
python -B -X utf8 06_离线工具/offline_demo.py --case functional --verify
python -B -X utf8 06_离线工具/offline_demo.py --case formal --formal-check
python -B -X utf8 06_离线工具/verify_package.py --full
```

默认回放的是本轮真实保存的候选、反馈和修复结果，不发模型请求。`--verify`用包内F1.4裁判重新执行给定候选的功能测试；`--formal-check`额外做最多30秒的有界检查。新复验输出不覆盖正式实验结果。

## 验证自己的ST候选

以包内正式题库为输入，运行原工程的题目CLI：

```powershell
python -B -X utf8 01_原工程/progress/f14_candidate/release/task.py public-medium-01 --candidate 你的候选.st --output 本次结果.json
```

单题候选未整题通过时，原CLI会返回非零退出码，同时保存详细测试结果，这是正常的判题输出。

## 查看真实CODESYS工程

本轮使用CODESYS V3.5 SP22 Patch 4，原生工程在`05_实验记录/原生编译工程`。可在相同平台中打开`.project`查看功能块、构建配置和编译日志；`原生编译索引.json`关联每个工程与原题次。原模板另行提供，自动化编译脚本在原工程stage3/scripts。

`.compileinfo`、`.precompilecache`和个人`.opt`属于可重建缓存/界面选项，未打包；打开工程后由CODESYS生成。包中不带软件安装程序和许可证。FIFO双实例仿真工程与14步验收记录单独保留，供展示平台适配与实际仿真流程。
