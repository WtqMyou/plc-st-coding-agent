# 给PPT与视频同学的操作卡

本文件提供素材和操作路径，视频由原分工同学拍摄。整个推荐演示不调用生成模型。

## 准备画面

打开根目录`00_先读我.html`，浏览器放大到易读字号。PNG直接插入PPT，SVG可用于高清缩放；数据CSV用于按组内风格重新绘图。

## 可录制的三个真实案例

1. **编译反馈**：自研DeepSeek配方管理题。打开native案例对照页，展示首轮CODESYS诊断，再展示修复后真实编译通过、19/21功能用例记录。原始`.project`与日志可按索引打开。
2. **功能反馈**：Codex MiniMax公共medium-04题。展示首轮10/37用例、实际功能反馈、修复代码和修复后27/37用例。运行`offline_demo.py --case functional --verify`可现场做本地功能复验。
3. **形式反馈**：自研DeepSeek公共多泵题。首轮功能12/12但存在规约反馈；修复后保持12/12，形式由`violated`转为`bounded_pass`。运行`--case formal --formal-check`可补录本地有界检查过程。

回放命令：

```powershell
python -B -X utf8 06_离线工具/offline_demo.py --case all
```

## 可采用的展示顺序

项目目标与Agent架构 → 两模型四组实验设置 → 首次/最终功能图 → 三类反馈案例 → 本轮成本与可追溯记录 → 工业辅助编程应用展望。

画面标题建议使用“真实实验记录回放”或“本地功能复验”，便于观众理解录制时展示的是已完成实验与真实离线执行。

本包未制作成品PPT或视频，以上是可直接复用的素材与操作卡，组员可以按自己的汇报节奏剪辑。
