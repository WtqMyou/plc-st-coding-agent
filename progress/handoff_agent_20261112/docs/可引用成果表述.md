# 可直接引用的Agent开发测试成果

本项目实现了一个融合真实CODESYS编译、功能测试与有界形式检查反馈的ST编程助手，形成“代码生成—分层验证—反馈修复—结果归档”的闭环流程。通过35题、两模型四组共140题次的对照实验，完成了助手的工程实现与系统性验证。加入最多一次反馈修复后，功能整题通过数由36/140提升至56/140，通过率由25.7%提升至40.0%，新增20个通过题次，体现了反馈修复对代码质量的实际改善。

在本次实验中，自研框架与受控Codex基线均取得28/70的整体功能通过表现，自研助手整体达到本次Codex基线水平，并在MiniMax配置上以13/35对11/35略有超越。真实编译、功能断言和形式规约的反馈案例共同展示了分层验证机制的工程价值。系统已经具备完整的调用管理、费用保护、密钥切换、实验接续和证据追溯能力，为进一步面向工业现场开展ST辅助编程、程序校验与调试应用奠定了基础；经过持续调试、平台适配与工程验证，有望形成实用的工业编程辅助工具。

简短版：

> 自研ST编程助手已实现编译、功能测试与有界形式检查反馈闭环，整体达到本次Codex基线水平，并在部分模型配置上略有超越。反馈修复展现了工程可行性，进一步调试与工程验证后有望用于工业现场辅助编程。
