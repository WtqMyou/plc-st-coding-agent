# Agent开发与测试成果交接

本包是Agent开发、测试与证据交接包，供两位同学分别开展PPT/视频制作和项目报告汇总/汇报。Agent侧的实现、正式实验与结果核对已完成；同学可直接使用本包中的原工程、数据、图表和案例，不需要重新发起付费实验。

## 先看哪里

1. 双击根目录`00_先读我.html`：总览、结果、图表、三个演示案例及全部资料入口。
2. PPT与视频同学：看`03_PPT视频素材/演示操作卡.md`，使用PNG/SVG图表与三个案例页面，按需运行`06_离线工具/一键回放.cmd`。
3. 报告汇总与汇报同学：看`04_数据与报告素材/报告资料索引.md`和结果CSV，按证据索引引用本轮结果。
4. 开发接手或技术答疑：看`02_说明/工程结构与模块说明.md`和`环境搭建与运行.md`。
5. 检查复制是否完整：运行`python -B -X utf8 06_离线工具/verify_package.py`。加`--full`可重新运行35题946条参考功能用例及三个案例的功能复验，全程不调用生成模型。

助手流程和反馈修复已展现工程可行性，形成了进一步开展工业现场辅助编程、程序校验与调试应用的实现基础；经过持续调试、平台适配和工程验证，有望拓展到实际工业编程场景。
