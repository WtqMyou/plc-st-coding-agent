# 公共题如何核对公开行为

**配料与输送。** 配料完成的触发要依据工作状态和公开命令；柔性加工线的验证器则根据公开路线、工位信号和前一拍按钮计算输送方向。合法配置下等待完成沿时，即使位置传感器已有效，也不应仅因此进入下一步。工序运行中改变未固定的路线值同样在验证范围内。[公共规约检查](public_specs.json) · [工序状态图](process_certificate.json)

**FIFO 与 IPv4。** FIFO 根据实际绑定求数组长度，并独立检查两个调用方的载荷顺序。IPv4 用合法性、数值和段数等公开观察量核对解析输出。对最后一段含前导零的地址给出正式输入，能检出仅在末段放宽校验的错解。[FIFO](fifo_bindings.md) · [IPv4 及其他公共题的反例](audit_public_other.json)
