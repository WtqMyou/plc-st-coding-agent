public-medium-04 Temperature Logic Control

题面

Write a function block FB to implement a temperature control logic. The program should include the following functions:
1. Read the value of the temperature sensor through an analog input module.
2. Compare the read temperature value TemperatureSensorInput with the set temperature value SetTemperature.
3. If the actual temperature is lower than the set temperature, start the heater HeaterOutput.
4. If the actual temperature is higher than the set temperature, turn off the heater HeaterOutput.
5. Each scan represents 1 second. The fifth consecutive heating-demand scan triggers protection and already turns the heater off. Cooling starts on the next scan: two scans remain off; the third clears protection and re-evaluates the current input. Cooling advances independently of sensor readings and faults.
6. Provide status indication, displaying the current temperature, set temperature, heater status, and whether overheating protection is triggered.
7. Provide temperature sensor fault judgment, if the read temperature value TemperatureSensorInput is less than 0 or greater than 100, it is considered a sensor fault, and the heater should be turned off.
本修订明确逐拍验收边界：每拍1秒。读数合法（0..100，含边界）且严格低于设定才有加热需求；等于设定或读数故障均关断并清连续加热计数。
连续需求第5拍触发过热保护，当拍已关断；从下一拍计冷却，前两拍保持关断，第3拍解除保护并按当拍读数重新决策。冷却计数独立于温度和故障；若解除当拍重新加热，该拍为下一轮第1拍。
连续低温时第1..4拍开，第5..7拍关，第8拍重新开。显示直通当前输入，HeaterStatus跟随HeaterOutput。

适配后参考代码

FUNCTION_BLOCK FB
VAR_INPUT
    TemperatureSensorInput : REAL;
    SetTemperature : REAL;
END_VAR
VAR_OUTPUT
    CurrentTemperature : REAL;
    SetTempDisplay : REAL;
    HeaterStatus : BOOL;
    OverheatProtection : BOOL;
    HeaterOutput : BOOL;
END_VAR
VAR
    onRun : INT;
    protectTimer : INT;
    fault : BOOL;
END_VAR

(* R6: 状态指示，当前温度与设定温度直通显示 *)
CurrentTemperature := TemperatureSensorInput;
SetTempDisplay := SetTemperature;

(* R7: 传感器故障判定：读数低于 0 或高于 100 视为故障 *)
fault := (TemperatureSensorInput < 0.0) OR (TemperatureSensorInput > 100.0);

IF OverheatProtection THEN
    (* R5: 过热保护期间强制关断加热；连续 3 拍（3s）冷却后解除 *)
    protectTimer := protectTimer + 1;
    IF protectTimer >= 3 THEN
        OverheatProtection := FALSE;
        protectTimer := 0;
        onRun := 0;
    ELSE
        HeaterOutput := FALSE;
    END_IF
END_IF

IF NOT OverheatProtection THEN
    (* R3/R4: 低于设定温度开加热，高于或等于设定温度关加热；
       传感器故障时禁止加热（R7 优先于 R3） *)
    IF fault THEN
        HeaterOutput := FALSE;
    ELSE
        HeaterOutput := TemperatureSensorInput < SetTemperature;
    END_IF

    (* R5: 连续加热计时，达到 5 拍（5s）即触发过热保护并立即关加热 *)
    IF HeaterOutput THEN
        onRun := onRun + 1;
        IF onRun >= 5 THEN
            OverheatProtection := TRUE;
            protectTimer := 0;
            onRun := 0;
            HeaterOutput := FALSE;
        END_IF
    ELSE
        onRun := 0;
    END_IF
END_IF

(* R6: 加热状态指示跟随实际加热输出 *)
HeaterStatus := HeaterOutput;
END_FUNCTION_BLOCK

self-hard-02 批次工艺阶段与运行时长统计（无外部时钟）

题面

写一个功能块 FB，管理间歇反应釜批次。初始 (phase, elapsed, timeout)=(0,0,FALSE)。
1. maxDuration 为正整数，单位为扫描拍；所有实数输入为有限值，不使用系统时钟或计时器。
2. 每拍先记录 startBtn 上升沿，包括中止当拍；按 中止 > 新启动沿 > 运行计数 的优先级处理。
3. abortBtn 为 TRUE 时立即进入 phase=9，elapsed 与 timeout 保持；同拍启动沿已消耗，重新启动必须松开再按。
4. 无中止且出现新启动沿时进入 phase=1，elapsed=0、timeout=FALSE；启动拍不计数。
5. 上一拍 phase 为1或2时先将 elapsed 加1。达到本拍 maxDuration 则 timeout=TRUE、phase=3，优先于升温达标；否则 phase=1 且 pv>=setpoint 时进入 phase=2。
6. phase=3 为完成态、phase=9 为中止态，两态冻结计数及超时标志，直到新的有效启动或中止。不设无接口支持的操作员确认。

适配后参考代码

FUNCTION_BLOCK FB
VAR_INPUT
    startBtn : BOOL;
    abortBtn : BOOL;
    setpoint : REAL;
    pv : REAL;
    maxDuration : INT;
END_VAR
VAR_OUTPUT
    elapsed : INT;
    phase : INT;
    timeout : BOOL;
END_VAR
VAR
    startEdgeInputPrev : BOOL;
    startEdge : BOOL;
END_VAR
startEdge := startBtn AND NOT startEdgeInputPrev;
startEdgeInputPrev := startBtn;
IF abortBtn THEN
    phase := 9;
ELSIF startEdge THEN
    phase := 1;
    elapsed := 0;
    timeout := FALSE;
ELSIF phase = 1 OR phase = 2 THEN
    elapsed := elapsed + 1;
    IF elapsed >= maxDuration THEN
        timeout := TRUE;
        phase := 3;
    ELSIF phase = 1 AND pv >= setpoint THEN
        phase := 2;
    END_IF
END_IF
END_FUNCTION_BLOCK

2. 需求为0时主备都清零；重新产生正需求时按排序初选主泵。需求1时备泵为0。

self-hard-05 燃烧状态与氧量修正联锁（熄火跳闸 + 分析仪故障降级）

题面

写一个功能块 FB，实现燃烧器的火焰联锁与烟气氧量修正。
控制要求：
1. 运行请求 runRequest 为 TRUE 且火焰探测器 flameOK 为 FALSE 时，**当拍**置位熄火跳闸 tripLatched，并切断燃料许可；
2. tripLatched 自保持，只有在 runRequest=FALSE 且 flameOK=FALSE（停机且无火焰的安全态）的前提下，resetBtn 的**上升沿**才能清除。复位是边沿命令而不是保持命令：按住的时长不影响判定，每拍只认有没有新的上升沿；复位那一刻条件不满足就无效，之后条件满足了但还按着（没有新上升沿）也**不得**清除；runRequest 仍为 TRUE 或 flameOK 仍为 TRUE 时按下的复位同样无效；
3. fuelPermit = runRequest AND flameOK AND NOT tripLatched；
4. 氧量修正：trimEnable = fuelPermit AND NOT o2Fault；airTrim = 2.0 * (2.0 - o2PV)，并钳位到 [-10, +10]；trimEnable=FALSE 时 airTrim 必须为 0.0。说明：±10 是**输出约束**，不代表两个方向都能到饱和——合法量程 0..21% 内原始修正只在 [-38, +4] 之间（o2PV=0 得 +4，o2PV=21 得 -38），因此正向限幅在本题永远不触发，只有 o2PV > 7.0 时负向限幅才起作用；增益偏小属于演示取舍，真实装置的风门增益取决于风道流通能力；
5. o2Fault = NOT o2Valid OR o2PV < 0.0 OR o2PV > 21.0（分析仪故障只切除修正，**不得**切除燃料；o2Valid=TRUE 但 o2PV<0 同样判故障）；
6. airCommand = baseAir + airTrim，钳位到 [0, 100]；fuelPermit=FALSE 时 airCommand 必须为 0.0。说明：baseAir 是外部基础开度给定，本题**不要求** baseAir 自身落在 0..100，只要求最终 airCommand 落在 0..100（baseAir+airTrim 可能为负，此时钳位到 0）；
7. 范围声明：本题只考核**运行阶段**的火焰联锁与氧量修正。预吹扫、点火、火焰建立等启动顺序，以及完整燃烧器安全管理（BMS，含吹扫时的风门要求）不在本题范围内，由其他系统负责。

self-hard-06 蒸汽母管超压联锁与故障线索诊断（按位编码 + 足迹保留）

题面

写一个功能块 FB，实现母管超压联锁，并在跳闸时记录**故障线索**。
控制要求：
1. 压力有效判据 pressureValid；>= 4500.0 kPa 判超压；
2. 跳闸条件（任一成立）：runRequest 且 pressureValid 且 pressure >= 4500.0；runRequest 且 NOT pressureValid（数据失效按最坏情况处理）；跳闸与本拍线索同拍生效；
3. tripLatched 自保持；清除条件：resetBtn 上升沿 且 NOT runRequest 且 pressureValid 且 pressure <= 4200.0。4500 与 4200 之间的 300 kPa 是**滞环**：复位门槛比跳闸门槛低 300 kPa，防止压力在阈值附近抖动导致反复跳闸/复位；
4. 线索位（currentCauseMask，WORD 的**低 4 位**，本拍重新计算）：
   bit0=1 变送器失效（runRequest 且 NOT pressureValid）；
   bit1=2 减温减压阀卡滞：outletCmd>=50 且 outletFeedback<=10 **连续 3 个执行周期及以上**；
   bit2=4 燃烧过剩：fuelFlow >= 4.0 且 steamFlow <= 10.0（比较的是接口流量数值，单位 t/h；两个边界都含等于）；
   bit1/bit2 只在「runRequest 且 pressureValid 且 pressure >= 4500.0」的超压工况下评估；若超压但以上线索都不成立，置 bit3=8（未定位）；
   NOT runRequest 时线索为 0；
5. 卡滞判据必须是**连续扫描周期**：中途反馈恢复、压力回落到 4500 以下、变送器失效或 runRequest=FALSE，都要把 3 拍计数清零——计数不清零就会把历史误当成“连续”；
6. latchedCauseMask：tripLatched 为 TRUE 时把 currentCauseMask **按位或**并入。注意 WORD 是 **16 位**（DWORD 才是 32 位），本题只用低 4 位（最大 15），16 位足够、不会溢出。该掩码保存的是“本次跳闸期间**全部历史线索的累积**”，**不是**跳闸瞬间的原因快照——跳闸后新出现的线索也会并入，只有合法复位才清零；因此它回答的是“这次跳闸期间一共观察到过哪些现象”，不能把它直接当成唯一的跳闸原因；
7. fuelPermit = runRequest AND NOT tripLatched；diagnosticActive = (currentCauseMask <> 0)。
取数与整定说明：
- 本块每个扫描周期执行一次，题目不定义扫描周期时长：“连续 3 拍”指连续3 个执行周期，不承诺固定秒数；
- 4500/4200 kPa 与 300 kPa 滞环是该算例的整定值（不据此推定具体装置额定压力或安全阀整定值），只用于考核联锁逻辑，不代表具体机组的最终整定；工程整定须依据母管设计压力与安全阀铭牌；
- 燃烧过剩判据 4.0/10.0 t/h 是“燃料流量偏高而蒸汽流量偏低”的算例阈值，同样只作算例参数，不是机组保护定值。

 pressure : REAL;
 pressureValid : BOOL;
 fuelFlow : REAL;
 steamFlow : REAL;
 outletCmd : INT;
 outletFeedback : INT;
 resetBtn : BOOL;
END_VAR

 tripLatched : BOOL;

END_VAR
VAR
 prevReset : BOOL;
 tripMem : BOOL;
 latMem : WORD;
 valveCnt : INT;
END_VAR
currentCauseMask := 0;
IF resetBtn AND NOT prevReset AND NOT runRequest AND pressureValid
 AND (pressure <= 4200.0) THEN
 tripMem := FALSE;
 latMem := 0;
 valveCnt := 0;
END_IF;
prevReset := resetBtn;
IF NOT runRequest THEN
 valveCnt := 0;
ELSIF NOT pressureValid THEN
 currentCauseMask := 16#0001;
 valveCnt := 0;
 tripMem := TRUE;
ELSIF pressureValid AND (pressure >= 4500.0) THEN
 IF (outletCmd >= 50) AND (outletFeedback <= 10) THEN
  valveCnt := valveCnt + 1;
  IF valveCnt > 3 THEN valveCnt := 3; END_IF;
 ELSE
  valveCnt := 0;
 END_IF;
 IF valveCnt >= 3 THEN
  currentCauseMask := currentCauseMask OR 16#0002;
 END_IF;
 IF (fuelFlow >= 4.0) AND (steamFlow <= 10.0) THEN
  currentCauseMask := currentCauseMask OR 16#0004;
 END_IF;
 IF currentCauseMask = 0 THEN
  currentCauseMask := 16#0008;
 END_IF;
 tripMem := TRUE;
ELSE
 valveCnt := 0;
END_IF;
IF tripMem THEN
 latMem := latMem OR currentCauseMask;
END_IF;
tripLatched := tripMem;
latchedCauseMask := latMem;
diagnosticActive := (currentCauseMask <> 0);
fuelPermit := runRequest AND NOT tripMem;
END_FUNCTION_BLOCK

self-hard-07 串级 PI 温控回路的手/自动无扰切换（bumpless transfer）

题面

写一个功能块 FB，实现**串级 PI 控制回路**的手/自动无扰切换。
1. 串级结构：外环以温度偏差驱动流量设定，内环以流量偏差驱动阀门开度；
2. 模式：0=手动（操作员直接给定流量设定与阀门开度，两者都跟随手动值）；1=自动（手动给定流量设定 manualFlowSP，内环 PI 自动算阀门）；2=串级（温度环 PI 算流量设定，流量环 PI 算阀门）；
3. 每个扫描周期只执行一次，scanSeconds 为本次周期时长（秒）；控制器系数按**秒**计算：外环 KiT=0.2 (t/h)/(℃·s)、内环 KiF=0.5 %/((t/h)·s)；温度偏差 eT=tempSP-tempPV（℃），流量偏差 eF=flowSP-flowPV（t/h），阀门开度单位 %，因此积分项 accT 的单位是t/h、accF 的单位是 %，增益 1.0 与 2.0 分别对应 ℃→t/h 与 t/h→% 的折算：
   外环 trial = accT + 0.2*eT*scanSeconds；flowSP = 1.0*eT + trial；限幅 0..50（t/h）；accT = flowSP - 1.0*eT；
   内环 trial = accF + 0.5*eF*scanSeconds；valveCommand = 2.0*eF + trial；限幅 0..100（%）；accF = valveCommand - 2.0*eF；
   抗积分饱和用**回算**：acc 取限幅后的实际输出反算，因此限幅期间积分不会越积越多、解除饱和后立即恢复；
4. 模式切换当拍不执行正常 PI 积分，normalMode=FALSE。切到串级 mode=2 时，flowSP 与 valveCommand 均保持上一拍值；切到自动/手动 mode=1/0 时，flowSP 跟随 manualFlowSP，valveCommand 保持上一拍值。连续两拍切换也必须逐拍识别。首次执行与复位、故障拍按初始化/复位/故障规则处理，不适用上一拍输出保持。手动接管后的正常拍允许操作员给定引起阀位突变。
5. 复位 resetBtn 上升沿：整个回路回到初值——预置积分器、输出跟手动值、当拍不运算；按住不放不重复动作；
6. 故障安全：mode 不在 0/1/2，或 scanSeconds<=0.0（时标丢失），或 scanSeconds>10.0（超过 10 s 的扫描周期视为时基异常）→ fault 置位，输出**立即**跟手动值、不积分，并预置积分器；故障期间允许阀位跳变（安全优先，与“无扰切换”区分）；
7. 复位/故障优先于正常运算：同一拍既有复位上升沿又有故障时，按复位处理（两者输出相同，均跟手动值）；
8. normalMode 表示“本拍处于正常运算”，即既不在复位拍也不在故障、也不在模式切换/首次执行拍；
9. 模式可以任意跳转（不要求 0→1→2 依次投入；直接 0→2 合法）；但工程上一般建议先投入内环（1）再投入外环（2），这样温度环 PI 的积分器在切换时已有较接近的初值、可减少切换瞬态——这是操作建议，不是本块强制的算法约束。
扫描周期与单位约定：scanSeconds 以秒给出，积分增益按秒定义，算法已显式乘 scanSeconds，不得再次折算。KpT=1.0 (t/h)/℃，KiT=0.2 (t/h)/(℃·s)，KpF=2.0 %/(t/h)，KiF=0.5 %/((t/h)·s)。离散采样周期会影响近似误差与闭环表现，不据此重复调整 Ki。输入契约：所有数值为有限值，manualFlowSP 在 0..50 t/h，manualValve 在 0..100%。
平台适配：原接口 dt（IEC 日期时间类型别名）统一重命名为 scanSeconds；单位秒、类型及原数字断言不变。

VAR_INPUT
 mode : INT;
 resetBtn : BOOL;
 scanSeconds : REAL;
 tempSP : REAL;
 tempPV : REAL;
 flowPV : REAL;
 manualFlowSP : REAL;
 manualValve : REAL;
END_VAR
VAR_OUTPUT
 flowSP : REAL;
 valveCommand : REAL;
 fault : BOOL;
 normalMode : BOOL;
END_VAR
VAR
 prevReset : BOOL;
 initDone : BOOL;
 lastMode : INT;
 accT : REAL;
 accF : REAL;
 oFlow : REAL;
 oValve : REAL;
 eTemp : REAL;
 eFlow : REAL;
 trial : REAL;
 normalMem : BOOL;
END_VAR
fault := (mode < 0) OR (mode > 2) OR (scanSeconds <= 0.0) OR (scanSeconds > 10.0);
normalMem := FALSE;
IF (NOT initDone) OR (resetBtn AND NOT prevReset) OR fault THEN
 oFlow := manualFlowSP;
 oValve := manualValve;
 accT := oFlow - 1.0 * (tempSP - tempPV);
 accF := oValve - 2.0 * (oFlow - flowPV);
 lastMode := mode;
 initDone := TRUE;
ELSIF lastMode <> mode THEN
 IF mode <> 2 THEN
  oFlow := manualFlowSP;
 END_IF;
 accT := oFlow - 1.0 * (tempSP - tempPV);
 accF := oValve - 2.0 * (oFlow - flowPV);
 lastMode := mode;
ELSE
 normalMem := TRUE;
 IF mode = 0 THEN
  oFlow := manualFlowSP;
  oValve := manualValve;
  accT := oFlow - 1.0 * (tempSP - tempPV);
  accF := oValve - 2.0 * (oFlow - flowPV);
 ELSIF mode = 1 THEN
  oFlow := manualFlowSP;
  accT := oFlow - 1.0 * (tempSP - tempPV);
  eFlow := oFlow - flowPV;
  trial := accF + 0.5 * eFlow * scanSeconds;
  oValve := 2.0 * eFlow + trial;
  IF oValve > 100.0 THEN oValve := 100.0; END_IF;
  IF oValve < 0.0 THEN oValve := 0.0; END_IF;
  accF := oValve - 2.0 * eFlow;
 ELSE
  eTemp := tempSP - tempPV;
  trial := accT + 0.2 * eTemp * scanSeconds;
  oFlow := 1.0 * eTemp + trial;
  IF oFlow > 50.0 THEN oFlow := 50.0; END_IF;
  IF oFlow < 0.0 THEN oFlow := 0.0; END_IF;
  accT := oFlow - 1.0 * eTemp;
  eFlow := oFlow - flowPV;
  trial := accF + 0.5 * eFlow * scanSeconds;
  oValve := 2.0 * eFlow + trial;
  IF oValve > 100.0 THEN oValve := 100.0; END_IF;
  IF oValve < 0.0 THEN oValve := 0.0; END_IF;
  accF := oValve - 2.0 * eFlow;
 END_IF;
END_IF;
prevReset := resetBtn;
flowSP := oFlow;
valveCommand := oValve;
normalMode := normalMem;
END_FUNCTION_BLOCK

self-medium-05 合格蒸汽产量与净收益累计（闭区间判定 + 数据故障冻结）

题面

写一个功能块 FB，按扫描周期累计锅炉的合格蒸汽产量、燃料消耗与净收益。
控制要求：
1. 合格判据：steamTemp 在 [447.0, 453.0] 且 steamPressure 在 [3750.0, 3850.0]（**闭区间**，端点合格；温度高于 453、压力低于 3750 或高于 3850 都判不合格）；
2. 本周期合格且 enable=TRUE 且无数据故障时，qualifiedTon += steamFlow * scanSeconds / 1000.0（流量按 kg/s、周期按 s 计，kg/s × s ÷ 1000 = t）；无论是否合格，只要 enable 且无故障，fuelTon += fuelFlow * scanSeconds / 1000.0；
3. 数据故障判据：scanSeconds <= 0.0 或 scanSeconds > 10.0（含恰好 10.0 合法、10.0 以上非法）或 steamFlow 不在 [0,90] 或 fuelFlow 不在 [0,6]（负流量同样判故障）；故障拍**不累计**，累计值保持不变；
4. resetBtn 上升沿：两个累计量清零，且**当拍不再累计**。复位是边沿命令、不是保持命令：按住的时长不影响判定，每拍只认有没有新的上升沿。**复位优先于故障冻结**：同一拍同时出现复位上升沿与数据故障时，先执行清零，清零结果生效（故障位仍如实报出，但累计量不得停留在旧值）；
5. revenue = qualifiedTon * 280.0，cost = fuelTon * 1500.0，netProfit = revenue - cost，三者每拍都要更新（即使不累计）。单价单位：蒸汽 280 元/t，燃料 1500 元/t，配 kg 换算后金额单位为元；
6. qualifiedTon、fuelTon、revenue、cost 必须非负；netProfit **允许为负**（烧燃料不产汽时会亏损）。enable=FALSE 时只更新 qualified/dataFault 两个判定位，不改累计量。
平台适配：原接口 dt（IEC 日期时间类型别名）统一重命名为 scanSeconds；单位秒、类型及原数字断言不变。

FUNCTION_BLOCK FB
VAR_INPUT
 enable : BOOL;
 resetBtn : BOOL;
 scanSeconds : LREAL;
 steamFlow : LREAL;
 fuelFlow : LREAL;
 steamTemp : LREAL;
 steamPressure : LREAL;
END_VAR
VAR_OUTPUT
 qualified : BOOL;
 dataFault : BOOL;
 qualifiedTon : LREAL;
 fuelTon : LREAL;
 revenue : LREAL;
 cost : LREAL;
 netProfit : LREAL;
END_VAR
VAR
 prevReset : BOOL;
 qTon : LREAL;
 fTon : LREAL;
END_VAR
qualified := (steamTemp >= 447.0) AND (steamTemp <= 453.0)
 AND (steamPressure >= 3750.0) AND (steamPressure <= 3850.0);
dataFault := (scanSeconds <= 0.0) OR (scanSeconds > 10.0)
 OR (steamFlow < 0.0) OR (steamFlow > 90.0)
 OR (fuelFlow < 0.0) OR (fuelFlow > 6.0);
IF resetBtn AND NOT prevReset THEN
 qTon := 0.0;
 fTon := 0.0;
ELSIF enable AND NOT dataFault THEN
 fTon := fTon + fuelFlow * scanSeconds / 1000.0;
 IF qualified THEN
  qTon := qTon + steamFlow * scanSeconds / 1000.0;
 END_IF;
END_IF;
prevReset := resetBtn;
qualifiedTon := qTon;
fuelTon := fTon;
revenue := qTon * 280.0;
cost := fTon * 1500.0;
netProfit := revenue - cost;
END_FUNCTION_BLOCK

self-medium-06 温度模糊控制与输出钳位（重心法 + 历史误差清除）

题面

写一个功能块 FB，用九条规则的温度模糊控制器计算加热功率。
控制要求：
1. e = setpoint - temperature；de = (e - ePrev) / scanSeconds，**首拍**或历史被清除时 de = 0；
2. x = clamp(e / 10.0, -1, 1)，y = clamp(de / 2.0, -1, 1)。量程说明：±10 ℃ 与 ±2 ℃/s 是本演示的满量程假设（对应温度回路约 ±10 ℃、变化率 ±2 ℃/s 的振荡工况；按幅值 ±10 ℃、周期 31.4 s 估算，变化率峰值约 2.0 ℃/s，该假设在演示工况下自洽），换到真实装置应按实际量程重新整定；
3. 隶属度：μN(z)=max(-z,0)、μZ(z)=1-|z|、μP(z)=max(z,0)；
4. 九条规则的单点输出：N×N=-30、N×Z=-20、N×P=-10、Z×N=-10、Z×Z=0、Z×P=10、P×N=10、P×Z=20、P×P=30；correction = Σ(w·c)/Σw（重心法），Σw=0 时 correction=0；
5. power = clamp(bias + correction, 0, 100)，**correction 不钳位**；
6. fault = NOT sensorValid OR scanSeconds <= 0.0 OR scanSeconds > 10.0；fault、enable=FALSE 或 resetBtn **上升沿**时：power=0、correction=0，并清除历史（ePrev=0、历史标志=FALSE）。复位是边沿命令、不是停机保持命令：按住的时长不影响判定，每拍只认有没有新的上升沿；按住复位期间输出的 0 只在上升沿那一拍成立，之后回到正常模糊计算（历史已清除，所以恢复后的首拍按 de=0 处理）。“首拍/复位后/故障或禁用后恢复的首拍”指历史标志为 FALSE 的那一拍，该拍 ePrev 不参与，de 一律取 0；下一拍起才用正常差分。
平台适配：原接口 dt（IEC 日期时间类型别名）统一重命名为 scanSeconds；单位秒、类型及原数字断言不变。

FUNCTION_BLOCK FB
VAR_INPUT
 enable : BOOL;
 resetBtn : BOOL;
 sensorValid : BOOL;
 setpoint : REAL;
 temperature : REAL;
 scanSeconds : REAL;
 bias : REAL;
END_VAR
VAR_OUTPUT
 power : REAL;
 correction : REAL;
 fault : BOOL;
END_VAR
VAR
 prevReset : BOOL;
 prevE : REAL;
 hasHist : BOOL;
 eNow : REAL;
 eDe : REAL;
 xx : REAL;
 yy : REAL;
 mx : REAL;
 zx : REAL;
 px : REAL;
 my : REAL;
 zy : REAL;
 py : REAL;
 wsum : REAL;
 wc : REAL;
 cOut : REAL;
 edgeReset : BOOL;
END_VAR
fault := (NOT sensorValid) OR (scanSeconds <= 0.0) OR (scanSeconds > 10.0);
edgeReset := resetBtn AND NOT prevReset;
IF edgeReset OR (NOT enable) OR fault THEN
 cOut := 0.0;
 hasHist := FALSE;
 prevE := 0.0;
ELSE
 eNow := setpoint - temperature;
 IF hasHist THEN
  eDe := (eNow - prevE) / scanSeconds;
 ELSE
  eDe := 0.0;
 END_IF;
 xx := eNow / 10.0;
 IF xx > 1.0 THEN xx := 1.0; END_IF;
 IF xx < -1.0 THEN xx := -1.0; END_IF;
 yy := eDe / 2.0;
 IF yy > 1.0 THEN yy := 1.0; END_IF;
 IF yy < -1.0 THEN yy := -1.0; END_IF;
 mx := MAX(-xx, 0.0);
 zx := 1.0 - ABS(xx);
 px := MAX(xx, 0.0);
 my := MAX(-yy, 0.0);
 zy := 1.0 - ABS(yy);
 py := MAX(yy, 0.0);
 wsum := mx * my + mx * zy + mx * py + zx * my + zx * zy + zx * py
  + px * my + px * zy + px * py;
 wc := mx * my * (-30.0) + mx * zy * (-20.0) + mx * py * (-10.0)
  + zx * my * (-10.0) + zx * zy * 0.0 + zx * py * 10.0
  + px * my * 10.0 + px * zy * 20.0 + px * py * 30.0;
 IF wsum > 0.0 THEN
  cOut := wc / wsum;
 ELSE
  cOut := 0.0;
 END_IF;
 prevE := eNow;
 hasHist := TRUE;
END_IF;
prevReset := resetBtn;
correction := cOut;
IF edgeReset OR (NOT enable) OR fault THEN
 power := 0.0;
ELSE
 power := bias + cOut;
 IF power > 100.0 THEN power := 100.0; END_IF;
 IF power < 0.0 THEN power := 0.0; END_IF;
END_IF;
END_FUNCTION_BLOCK
