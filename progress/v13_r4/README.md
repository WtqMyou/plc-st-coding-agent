性质总数220，原始LTL192、运行期LTL196。五道工业题和批次题的公式在给定参考测试序列上复验；全域5秒诊断另外归档，不冒称穷尽证明。缩域变异诊断只在显式列出的范围内成立，不改变正式mc_inputs。

## 复现和下一步

仓库根目录下检查冻结完整性：

```powershell
python -B -X utf8 progress/tools/v13_r4.py check
python -B -X utf8 -m unittest discover -s progress/tests -p test_v13_r4.py -q
```

build/verify/diagnostics/rescore/review只用于首次构建；冻结后拒绝覆盖，后续改动必须另立版本。使用r4_judge.local_tests/evaluate，不能将本版多组用例交给旧r3入口后误称全部已计分。新evaluate在一个总时限内执行本地工作进程、所需平台编译和形式检查，不复用旧裁判缓存。

下一阶段先收回本版工艺结论，并从本版JSON生成对应的Word汇编；当前531例Word保留原件，不作为583例新版。若继续小规模模型对照，应先冻结同一份数据、适配、裁判和预算；MiniMax输出额度或修复窗口每轮只改变一个因素。不得将r4结果与旧版另一组混作正式对比，也不以缩域提高通过分母。
