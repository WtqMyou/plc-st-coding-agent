## 计数与载荷边界

自建灌装题的当日瓶数使用 INT。从零开始，第 65,536 拍确认第 32,768 瓶时，先加一再存回 INT 会变成 −32,768。本版规定满量程后计数保持 32,767，灌装和确认继续执行。复位清零后，下一瓶实测计为 1。[灌装长轨迹](review/audit_self_other.json)

公共鼓风机及板厚题的计数输出均为 UINT。实测达到第 65,536 次事件时，鼓风机参考回绕为 0，板厚参考保持 65,535 并继续更新故障历史。课程题面未规定溢出策略。公共 FIFO 的载荷专项覆盖容量 2 和 4 的固定 DINT 调用方；对只错读队首、拒绝操作时误写数据的 3 个错解另行核对。[公共计数边界](review/audit_public_limits.json) · [公共 FIFO 载荷](review/public_fifo_payload.json)
