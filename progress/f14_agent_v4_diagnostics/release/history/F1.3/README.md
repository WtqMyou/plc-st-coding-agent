# STBench · 基于队友复验包的完整交付

队友《复验包_20261108.zip》是本包唯一的修改对照基线。七道随包题可实际复跑、按字段比较；其余 28 题的原始统计取自来件清单，本包另交付其可运行题目、参考实现及复验证据。[35 题逐题修改说明](35题逐题修改说明.md) · [审核与修改记录](审核与修改记录.md)

在含 `run.py` 的目录运行：

```text
python -B -X utf8 run.py
python -B -X utf8 verify_release.py --quick
```

第一条执行当前 35 题的功能评分。第二条核对文件哈希和来源，从保留的来件文件重放七题，再运行全库功能、轨迹检查并核对证明文件。完整重跑显式搜索与符号求解可用 `python -B -X utf8 verify_release.py --bounds --proofs`，需要本机 Z3。默认 `verify_release.py` 还会重放定向错解和专用检查。
