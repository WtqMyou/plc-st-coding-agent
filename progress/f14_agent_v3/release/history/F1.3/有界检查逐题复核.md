## 有界结论如何理解

- 自建物料 FIFO 的声明深度为 18 拍，其余题为 8 拍。符号检查对含下一拍的公式另展开相应的后继。通过的非空公式按编号计数；同一工艺行为可能被多条公式约束。
- 公共 FIFO 的正式模型覆盖两个固定 DINT 数组。独立载荷证据核对这两种容量的出队顺序和拒绝时的数据保持；未把结论扩展到任意类型、其他容量或调用方中途覆盖缓冲。[两个绑定的控制复核](review/fifo_bindings.json) · [载荷闭包](review/public_fifo_payload.json)
- 用例预置的满配方库、接近计数上限的特定前态、超出声明深度的长轨迹均按各专项的实测范围解释。长轨迹的结果记录在对应专项里。[公共难题的错解及范围](review/公共难题_逐条反例与适用范围.md)
