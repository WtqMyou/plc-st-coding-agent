# 自建物料 FIFO

self-hard-03 每拍有两路按钮和 15 个候选物料号。先出后入决定本拍有效长度；只断言有效的数组前缀，未用尾槽可以保留任意值。将本拍新物料和上拍的不同槽位赋予不同标记，能够检查搬移和队首写回是否来自正确的位置。

从声明初态覆盖 18 拍，共检查 282 个控制状态、1,016 条代表转移，7 条非空 LTL 通过。加入深度扩展后在第 19 层闭合；另用具体载荷逐条枚举 3 拍，检测错报满队、错误空队出队和输出恒零等变异。[正式搜索与具体树对照](material_fifo_bounds.json) · [有效前缀反例](audit_self_other.json)
