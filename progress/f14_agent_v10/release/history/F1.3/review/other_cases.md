# 自建队列、闸门与滑动窗口

| 题目 | 需要观察的状态 | 核验方法 |
|---|---|---|
| self-hard-03 物料 FIFO | 先出后入的计数、队首、有效前缀 | 检查物料号实际来源，满队拒绝和出队后多次移动分别计入测试。 |
| self-medium-03 闸门 | 闸门方向、遇障停机、双键确认清故障 | 用有历史的按钮序列区分电平和边沿；组合按钮产生新沿时，不能要求两个按钮同拍各自上升。 |
| self-medium-02 滑动平均 | 未填满时的分母、淘汰最老样本、停用保持 | 检查首个负样本和第二个样本的正确均值，并通过第九个样本核实淘汰顺序。 |

另外用独立队列模型复核 243 拍、窗口模型复核 178 拍；物料 FIFO 和滑窗口另有覆盖更多输入历史的符号检查。[独立数值与队列对照](other_cases.json) · [三个题目的实际变异](audit_self_other.json)
