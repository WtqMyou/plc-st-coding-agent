# 显式搜索如何计数

显式搜索从声明初态逐拍给参考程序输入，每条边代表一次实际执行的输入转移。状态键要同时保留后续 ST 仍可能读取的记忆和每条 LTL 所需的过去值；含下一拍的性质要保留尚待判定的窗口。对于调用方固定的参数，首次选定的值属于状态的一部分。新输入到达已有状态时，先检查该条边上的性质，再决定是否需要继续展开。

“小于预算上限”与“已穷尽”由不同字段区分。`completed_depth` 给出已经完整检查的层数；`stop_reason` 说明因深度完成、状态闭合、时间或迁移额度而退出。达到预算的题需要补充验证。[声明预算实测](declared_bounds.json) · [补充方法](coverage.json)

六组小域试验逐条枚举全部 592 条完整输入序列，与合并状态的算法比对，包括输入顺序对调、固定绑定、数组隔离和多拍前后依赖。记录还检查了短轨迹末端无法观察到后继时的判定、真实执行异常和预算截断。[穷举对照](search_equivalence.json)
