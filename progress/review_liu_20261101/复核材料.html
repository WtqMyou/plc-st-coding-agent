self-hard-05 · 燃烧状态与氧量修正联锁（熄火跳闸 + 分析仪故障降级）

待人工复核

建议核对

  • 熄火同拍跳闸、燃料许可与风量输出的关系是否明确？
  • 氧量分析仪故障仅切除修正的设定是否适合本题边界？
  • 复位上升沿及其前置条件、修正和风量的限幅是否合理？

题目与平台适配要求

写一个功能块 FB，实现燃烧器的火焰联锁与烟气氧量修正。
控制要求：
1. 运行请求 runRequest 为 TRUE 且火焰探测器 flameOK 为 FALSE 时，**当拍**置位熄火跳闸 tripLatched，并切断燃料许可；
2. tripLatched 自保持，只有在 runRequest=FALSE 且 flameOK=FALSE 的前提下，resetBtn 的**上升沿**才能清除；
3. fuelPermit = runRequest AND flameOK AND NOT tripLatched；
4. 氧量修正：trimEnable = fuelPermit AND NOT o2Fault；trimmer = 2.0 * (2.0 - o2PV)，并钳位到 [-10, +10]；trimEnable=FALSE 时 airTrim 必须为 0.0；
5. o2Fault = NOT o2Valid OR o2PV < 0.0 OR o2PV > 21.0（分析仪故障只切除修正，**不得**切除燃料）；
6. airCommand = baseAir + airTrim，钳位到 [0, 100]；fuelPermit=FALSE 时 airCommand 必须为 0.0。

self-hard-06 · 蒸汽母管超压联锁与故障线索诊断（按位编码 + 足迹保留）

待人工复核

建议核对

  • 压力单位 kPa，4500 跳闸与 4200 复位的闭区间和滞环是否明确？
  • 压力数据失效与复位的优先关系是否清楚？
  • 卡滞连续三拍及中断清零、线索位和历史足迹是否一致？三拍依赖扫描周期的假设是否应补充？

题目与平台适配要求

写一个功能块 FB，实现母管超压联锁，并在跳闸时记录**故障线索**。
控制要求：
1. 压力有效判据 pressureValid；>= 4500.0 kPa 判超压；
2. 跳闸条件（任一成立）：runRequest 且 pressureValid 且 pressure >= 4500.0；runRequest 且 NOT pressureValid（数据失效按最坏情况处理）；跳闸与本拍线索同拍生效；
3. tripLatched 自保持；清除条件：resetBtn 上升沿 且 NOT runRequest 且 pressureValid 且 pressure <= 4200.0（滞环，防抖动）；
4. 线索位（currentCauseMask，WORD，本拍重新计算）：bit0=1 变送器失效；bit1=2 减温减压阀卡滞（outletCmd>=50 且 outletFeedback<=10 连续 **3 拍及以上**，每拍须同时满足运行、压力有效且压力>=4500；任一中断清零）；bit2=4 燃烧过剩（fuelFlow >= 4.0 且 steamFlow <= 10.0）；若超压但以上线索都不成立，置 bit3=8（未定位）；NOT runRequest 时线索为 0；
5. latchedCauseMask：tripLatched 为 TRUE 时把 currentCauseMask **按位或**并入（32 位字，不会溢出），复位时清零；
6. fuelPermit = runRequest AND NOT tripLatched；diagnosticActive = (currentCauseMask <> 0)。

 prevReset : BOOL;

 latMem : WORD;
 valveCnt : INT;

currentCauseMask := 0;
IF resetBtn AND NOT prevReset AND NOT runRequest AND pressureValid
 AND (pressure <= 4200.0) THEN
 tripMem := FALSE;
 latMem := 0;
 valveCnt := 0;
END_IF;
prevReset := resetBtn;
IF NOT runRequest THEN
 valveCnt := 0;
ELSIF NOT pressureValid THEN
 currentCauseMask := 16#0001;
 valveCnt := 0;
 tripMem := TRUE;
ELSIF pressureValid AND (pressure >= 4500.0) THEN
 IF (outletCmd >= 50) AND (outletFeedback <= 10) THEN
  valveCnt := valveCnt + 1;
  IF valveCnt > 3 THEN valveCnt := 3; END_IF;
 ELSE
  valveCnt := 0;
 END_IF;
 IF valveCnt >= 3 THEN
  currentCauseMask := currentCauseMask OR 16#0002;
 END_IF;
 IF (fuelFlow >= 4.0) AND (steamFlow <= 10.0) THEN
  currentCauseMask := currentCauseMask OR 16#0004;
 END_IF;
 IF currentCauseMask = 0 THEN
  currentCauseMask := 16#0008;
 END_IF;
 tripMem := TRUE;
ELSE
 valveCnt := 0;
END_IF;
IF tripMem THEN
 latMem := latMem OR currentCauseMask;
END_IF;
tripLatched := tripMem;
latchedCauseMask := latMem;
diagnosticActive := (currentCauseMask <> 0);
fuelPermit := runRequest AND NOT tripMem;
END_FUNCTION_BLOCK

写一个功能块 FB，实现温度-流量串级 PI 控制的三模式无扰切换。
控制要求：
1. mode：0=手动、1=外环手动/内环自动、2=串级全自动；mode 不在 0..2、scanSeconds<=0 或 scanSeconds>10 判 fault；
2. 初始化、复位上升沿、fault 三者的当拍：flowSP = manualFlowSP、valveCommand = manualValve，并把积分项预置为无扰值：iT = flowSP - KpT*(tempSP-tempPV)，iF = valveCommand - KpF*(flowSP-flowPV)（KpT=1.0，KpF=2.0）；
3. **模式切换的当拍不做积分**：阀位保持上一拍；切到 mode=2 时 flowSP 也保持上一拍，切到其它模式时 flowSP 跟 manualFlowSP；切换拍同时按上面公式重算 iT、iF；
4. 正常运算拍（normalMode=TRUE）：
   mode=0：flowSP=manualFlowSP、valveCommand=manualValve，重算 iT、iF；
   mode=1：flowSP=manualFlowSP、iT 按公式跟踪；eF=flowSP-flowPV，iF += KiF*eF*scanSeconds（KiF=0.5），valveCommand=clamp(KpF*eF+iF,0,100)，随后 iF=valveCommand-KpF*eF；
   mode=2：eT=tempSP-tempPV，iT += KiT*eT*scanSeconds（KiT=0.2），flowSP=clamp(KpT*eT+iT,0,50)，iT=flowSP-KpT*eT；再按 mode=1 的公式算内环；
5. 模式切换的识别：非初始化拍比较 mode 与内部上一模式；即使连续两拍切换也必须识别；初始化记录当前 mode；下一合法非复位拍 mode 未变则正常运算（与 q2 一致），mode 变化则切换保持；
6. normalMode 输出：本拍按正常 PI 规则运算则为 TRUE，初始化/切换/故障拍为 FALSE。调用方保证 manualFlowSP 在 [0,50]、manualValve 在 [0,100]；输入均为有限数。

  • 九条规则和加权输出、功率限幅与修正量的区别是否一致？
  • 首次扫描、禁用、故障和复位清除历史后的恢复行为是否覆盖？

题目与平台适配要求

写一个功能块 FB，用九条规则的温度模糊控制器计算加热功率。
控制要求：
1. e = setpoint - temperature；de = (e - ePrev) / scanSeconds，**首拍**或历史被清除时 de = 0；
2. x = clamp(e / 10.0, -1, 1)，y = clamp(de / 2.0, -1, 1)；
3. 隶属度：μN(z)=max(-z,0)、μZ(z)=1-|z|、μP(z)=max(z,0)；
4. 九条规则的单点输出：N×N=-30、N×Z=-20、N×P=-10、Z×N=-10、Z×Z=0、Z×P=10、P×N=10、P×Z=20、P×P=30；correction = Σ(w·c)/Σw（重心法），Σw=0 时 correction=0；
5. power = clamp(bias + correction, 0, 100)，**correction 不钳位**；
6. fault = NOT sensorValid OR scanSeconds <= 0.0 OR scanSeconds > 10.0；fault、enable=FALSE 或 resetBtn 上升沿时：power=0、correction=0，并清除历史（ePrev=0、历史标志=FALSE）。
平台适配：原接口 dt（IEC 日期时间类型别名）统一重命名为 scanSeconds；单位秒、类型及原数字断言不变。

 zx := 1.0 - ABS(xx);

 my := MAX(-yy, 0.0);
 zy := 1.0 - ABS(yy);
 py := MAX(yy, 0.0);
 wsum := mx * my + mx * zy + mx * py + zx * my + zx * zy + zx * py
  + px * my + px * zy + px * py;
 wc := mx * my * (-30.0) + mx * zy * (-20.0) + mx * py * (-10.0)
  + zx * my * (-10.0) + zx * zy * 0.0 + zx * py * 10.0
  + px * my * 10.0 + px * zy * 20.0 + px * py * 30.0;
 IF wsum > 0.0 THEN
  cOut := wc / wsum;
 ELSE
  cOut := 0.0;
 END_IF;
 prevE := eNow;
 hasHist := TRUE;
END_IF;
prevReset := resetBtn;
correction := cOut;
IF edgeReset OR (NOT enable) OR fault THEN
 power := 0.0;
